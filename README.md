# Asra Nawaz - Portfolio Website

A modern, responsive portfolio website built with React and Vite showcasing projects, skills, and professional journey.

## Features

- Dark/Light mode toggle
- Smooth scrolling navigation
- Typing animation in hero section
- Project filtering (All / React / Web)
- Animated skill progress bars
- Scroll reveal animations
- Download resume button
- Back to top button
- Responsive mobile menu
- Contact form

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Customization

Edit `src/data/portfolioData.js` to update:

- Personal information (email, phone, social links)
- Projects (descriptions, links, technologies)
- Skills and experience
- About section content

Place your resume PDF at `public/resume.pdf` for the download button.

## Tech Stack

- React 18
- Vite 6
- React Icons
- CSS3 with CSS Variables
